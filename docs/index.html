Staff notes

This page previews the Northern Lights Watch. To place it on a trlibrary.com page, paste this into a code block:

<div id="trpl-aurora"></div>
<script src="https://aurora.labs.trlibrary.com/aurora.js" defer></script>

Add data-heading="off" to the script tag when the page already has its own heading.

Trip planner only

<div id="trpl-aurora-plan"></div>
<script src="https://aurora.labs.trlibrary.com/aurora.js" data-view="planner" data-target="#trpl-aurora-plan" defer></script>

Compact (sidebar or homepage)

<div id="trpl-aurora-mini"></div>
<script src="https://aurora.labs.trlibrary.com/aurora.js" data-view="compact" data-target="#trpl-aurora-mini" data-more="https://www.trlibrary.com/..." defer></script>
